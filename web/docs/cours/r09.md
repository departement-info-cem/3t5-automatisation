# Formatif 1: Lignes de commande

Cet examen formatif est une **pratique de l'examen 1** comptant pour **15%** de la note finale du cours (soit **30%** du seuil des examens). Il porte sur les lignes de commande PowerShell.

## Contexte de réalisation

Vous avez **2 heures** pour le terminer.

Ce qui est permis pendant l'examen:

- Les site du cours
- Les fichiers PowerPoint
- Une feuille de notes personnelles 8&frac12;x11 manuscrite recto-verso

Toute autre documentation est interdite (OneNote, GitHub, le code du TP, etc.)

:::info Examen formatif
Puisqu'il s'agit d'un examen formatif, vous n'aurez pas de sanction si vous accédez à de la documentation interdite. Celà dit, vous êtes fortement encouragé à vous conformer à ces restrictions afin que la simulation soit réaliste.

Si vous bloquez sur une question, vous pouvez demander de l'aide au professeur (vous ne pourrez pas le faire pendant l'examen sommatif).
:::
