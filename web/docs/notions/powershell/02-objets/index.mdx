title: "Les objets"
---

Les commandes PowerShell retournent un ou plusieurs objets. Un objet est une structure de données, un élément logique d'information d'une structure définie par une classe (ou type). Il est composé de plusieurs membres, soit des propriétés (ou méthodes), qui représentent de l'information décrivant l'objet, et des méthodes (ou fonctions) qui posent une action sur cet objet.

## Connaître les membres d'un objet

La commande `Get-Member` permet d'obtenir la liste des propriétés et des méthodes offertes par cet objet. Dans le cas d'une collection d'objets, elle analyse le type d'objet dans la collection.

## Obtenir une propriété

Par exemple, la commande `Get-Item` retourne l'information sur un fichier ou un dossier. Le résultat de cette commande est un objet qui décrit le fichier ou le dossier correspondant.

<ConsoleWindow title="PowerShell 7" backgroundColor="#000046">
```text
PS C:\> Get-Item C:\Windows\notepad.exe

    Directory: C:\Windows

Mode                 LastWriteTime         Length Name
----                 -------------         ------ ----
-a---          2026-07-28    21:53         360448 notepad.exe
```
</ConsoleWindow>

Si l'objet représente un fichier, il possèdera une propriété `.Length` qui représente sa taille, en octets. Pour accéder à un membre d'un objet, on utilise le caractère point. Il y a plusieurs manières d'identifier l'objet, soit avec des parenthèses, soit en le passant dans une variable.

<ConsoleWindow title="PowerShell 7" backgroundColor="#000046">
```text
PS C:\> (Get-Item C:\Windows\notepad.exe).Length
360448
PS C:\> $MonFichier = Get-Item C:\Windows\notepad.exe
PS C:\> $MonFichier.Length
360448
PS C:\> (Get-Item C:\Windows\notepad.exe).Length / 1KB
352
```
</ConsoleWindow>

:::tip Des objets dans des objets
Parfois, une propriété d'un objet est elle aussi un objet. Par exemple, `Get-Culture` donne la configuration des paramètres régionaux de votre session Windows.

<ConsoleWindow title="PowerShell 7" backgroundColor="#000046">
```text
PS C:\> Get-Culture | Select-Object *
(...)
CultureTypes                   : SpecificCultures, InstalledWin32Cultures
NumberFormat                   : System.Globalization.NumberFormatInfo
DateTimeFormat                 : System.Globalization.DateTimeFormatInfo
Calendar                       : System.Globalization.GregorianCalendar
(...)
```
</ConsoleWindow>

L'objet retourné par la commande semble posséder l'information sur le format de date et de temps, car il existe une propriété `DateTimeFormat`. Cependant, l'information est ambiguë. En fait, `System.Globalization.DateTimeFormatInfo` est un nom de classe. 

<ConsoleWindow title="PowerShell 7" backgroundColor="#000046">
```text
PS C:\> (Get-Culture).DateTimeFormat
(...)
ShortestDayNames                 : {D, L, M, M…}
DayNames                         : {dimanche, lundi, mardi, mercredi…}
AbbreviatedMonthNames            : {janv., févr., mars, avr.…}
MonthNames                       : {janvier, février, mars, avril…}
IsReadOnly                       : True
(...)
```
</ConsoleWindow>

On peut donc naviguer dans la structure d'objets, comme le montre l'exemple ci-dessous.

<ConsoleWindow title="PowerShell 7" backgroundColor="#000046">
```text
PS C:\> (Get-Culture).DateTimeFormat.DayNames
dimanche
lundi
mardi
mercredi
jeudi
vendredi
samedi
```
</ConsoleWindow>

## Connaître le type d'un objet

Une manière de connaître le type d'un objet est d'appeler sa méthode `GetType()`. Cette méthode existe dans tous les types d'objets, et retourne un objet qui décrit le type de cet objet. 

:::tip Appel de méthodes
Le membre `.GetType` n'est pas une propriété mais une **méthode**. Il faut obligatoirement que le nom du membre soit suivi de **parenthèses**. Selon la méthode, il pourrait y avoir des arguments dans les parenthèses. Certaines méthodes, comme `GetType()`, n'admet aucun argument; on doit tout de même écrire des parenthèses vides.

Les méthodes n'apparaissent pas avec `Select-Object *` puisque ce ne sont pas des propriétés. Vous pouvez toutefois les voir avec `Get-Member`.

<ConsoleWindow title="PowerShell 7" backgroundColor="#000046">
```text
PS C:\> Get-Item C:\Windows\notepad.exe | Get-Member -MemberType Method

   TypeName: System.IO.FileInfo

Name                      MemberType Definition
----                      ---------- ----------
(...)
Encrypt                   Method     void Encrypt()
Equals                    Method     bool Equals(System.Object obj)
GetHashCode               Method     int GetHashCode()
GetLifetimeService        Method     System.Object GetLifetimeService()
GetObjectData             Method     void GetObjectData(System.Runtime.Serializ…
GetType                   Method     type GetType()
InitializeLifetimeService Method     System.Object InitializeLifetimeService()
(...)
```
</ConsoleWindow>
:::

Par exemple, la commande Get-Item peut retourner des fichiers et des dossiers, qui sont des structures très différentes. Selon l'élément que l'on tente d'obtenir, le type de l'objet résultant sera différent.

<ConsoleWindow title="PowerShell 7" backgroundColor="#000046">
```text
PS C:\> (Get-Item C:\Windows\notepad.exe).GetType()

IsPublic IsSerial Name                                     BaseType
-------- -------- ----                                     --------
True     False    FileInfo                                 System.IO.FileSystemInfo

PS C:\> (Get-Item C:\Windows\System32).GetType()

IsPublic IsSerial Name                                     BaseType
-------- -------- ----                                     --------
True     False    DirectoryInfo                            System.IO.FileSystemInfo
```
</ConsoleWindow>

Si la commande retourne plusieurs objets, alors le type de l'objet retourné sera un array, c'est-à-dire un objet qui contient plusieurs objets. On les identifie avec des crochets à la fin de leur type, par exemple `Object[]`.

<ConsoleWindow title="PowerShell 7" backgroundColor="#000046">
```text
PS C:\> (Get-ChildItem C:\Windows).GetType()

IsPublic IsSerial Name                                     BaseType
-------- -------- ----                                     --------
True     True     Object[]                                 System.Array
```
</ConsoleWindow>
